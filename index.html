Run Claude Code with free models like NVIDIA NIM, OpenRouter, or fully local ones. No Anthropic API key needed. Both repos are below with their links, full setup, and every command ready to copy.

Before you start

You need these two things for both repos.

1

Get a free NVIDIA NIM API key

NVIDIA NIM gives you 40 requests a minute for free. Sign in and create a key here:

build.nvidia.com/settings/api-keys

Your key starts with nvapi-. Keep it private.

2

Install Claude Code

Needs Node.js installed. Skip this if you already have Claude Code.

npm install -g @anthropic-ai/claude-code
1

Alishahryar1 / free-claude-code

The original project. Easiest setup: one installer, then everything is done from a browser dashboard.

Repo: github.com/Alishahryar1/free-claude-code
1

Run the installer

Pick your system. When it asks, choose at least one coding agent (pick Claude Code).

curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh

Paste into Windows PowerShell

& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))
2

Start Free Claude Code

Windows: open Free Claude Code from your desktop or Start menu.
macOS: open Free Claude Code from your desktop or Applications folder.
Linux: run this and keep the terminal open:

fcc-server

The Admin UI opens in your browser once it starts.

3

Add your NVIDIA key in the Admin UI

  1. Open the Admin UI.
  2. Paste your key into NVIDIA_NIM_API_KEY.
  3. Leave MODEL on the default, or search the dropdown for another model.
  4. Click Apply.

The default model is:

nvidia_nim/nvidia/nemotron-3-super-120b-a12b
4

Launch Claude Code

Open a new terminal and run:

fcc-claude

That's it. Claude Code now runs on your free model. Use /model inside Claude Code to switch models.

Using a different agent? Same idea:

fcc-codex      # Codex
fcc-opencode   # OpenCode
fcc-cline      # Cline
fcc-aider      # Aider
5

Optional: use it inside VS Code

  1. Install the Claude Code extension in VS Code.
  2. Start Free Claude Code.
  3. In the Admin UI, go to Integrations and click Connect on the Claude Code in VS Code card.
  4. Reload VS Code.
6

Keep it updated

Stop any running FCC commands first, then:

fcc-update

Something not working? This prints a report you can paste into a GitHub issue:

fcc-doctor

codeaashu / free-claude-code

The lightweight version. You run the proxy yourself in one terminal and Claude Code in another.

Repo: github.com/codeaashu/free-claude-code
1

Install uv

uv is the Python tool this project runs on.

pip install uv

Already have uv? Update it instead:

uv self update
2

Clone the repo

git clone https://github.com/codeaashu/free-claude-code.git
cd free-claude-code
3

Create your .env file

Create a file named .env inside the free-claude-code folder and paste one of these. Replace the key with your own.

NVIDIA_NIM_API_KEY="nvapi-your-key-here"

MODEL_OPUS=
MODEL_SONNET=
MODEL_HAIKU=
MODEL="nvidia_nim/z-ai/glm4.7"

ENABLE_THINKING=true

Get a key at openrouter.ai/keys.

OPENROUTER_API_KEY="sk-or-your-key-here"

MODEL_OPUS="open_router/deepseek/deepseek-r1-0528:free"
MODEL_SONNET="open_router/openai/gpt-oss-120b:free"
MODEL_HAIKU="open_router/stepfun/step-3.5-flash:free"
MODEL="open_router/stepfun/step-3.5-flash:free"

No key needed. Start LM Studio's local server and load a model first.

MODEL_OPUS="lmstudio/unsloth/MiniMax-M2.5-GGUF"
MODEL_SONNET="lmstudio/unsloth/Qwen3.5-35B-A3B-GGUF"
MODEL_HAIKU="lmstudio/unsloth/GLM-4.7-Flash-GGUF"
MODEL="lmstudio/unsloth/GLM-4.7-Flash-GGUF"
4

Terminal 1: start the proxy

uv run uvicorn server:app --host 0.0.0.0 --port 8082

Leave this terminal running.

5

Terminal 2: run Claude Code through the proxy

ANTHROPIC_AUTH_TOKEN="freecc" ANTHROPIC_BASE_URL="http://localhost:8082" claude
$env:ANTHROPIC_AUTH_TOKEN="freecc"; $env:ANTHROPIC_BASE_URL="http://localhost:8082"; claude
Tip: use http://localhost:8082 exactly. Don't add /v1 at the end.
6

Optional: use it inside VS Code

  1. Keep the proxy running from step 4.
  2. Open VS Code settings (Ctrl + , or Cmd + ,) and search claude-code.environmentVariables.
  3. Click Edit in settings.json and add this:
"claudeCode.environmentVariables": [
  { "name": "ANTHROPIC_BASE_URL", "value": "http://localhost:8082" },
  { "name": "ANTHROPIC_AUTH_TOKEN", "value": "freecc" }
]

Reload extensions. If a login screen shows up, click Anthropic Console and authorise. It works even if it then asks you to buy credits, so you can ignore that. To go back to normal Claude, remove this block and reload.
